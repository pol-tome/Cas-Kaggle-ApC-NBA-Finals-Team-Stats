## 📖 Descripción del Proyecto

Este repositorio contiene el análisis y modelado de datos para el **Kaggle Case Study: NBA Finals Team Stats**.

El objetivo principal es analizar la evolución del baloncesto en las finales de la NBA desde 1980 hasta 2018 y desarrollar modelos de Machine Learning capaces de predecir la victoria de un equipo basándose en sus estadísticas de juego.

El proyecto abarca desde la limpieza de datos y análisis exploratorio (EDA) hasta la implementación de algoritmos de clasificación y visualización de resultados.
